# DSOA-10: UX Prototype for Older Adults

## Project
Development of a Web Application for Enhancing Digital Skills of Older Adults

## Interactive Prototype
https://www.figma.com/proto/HaN0aNf1TuBAROwesVV3Tt/DSOA_10?node-id=0-1&t=NcSbk3gysej19kNk-1

## Main Screens
1. Registration
2. Login
3. Initial Skills Assessment
4. Learning Dashboard
5. Lesson Catalogue
6. Step-by-Step Lesson
7. Interactive Exercise
8. Exercise Feedback
9. Progress Tracking

## Main User Flow
Registration → Initial Assessment → Dashboard → Lessons → Interactive Exercise → Feedback → Progress Tracking.

## Accessibility Considerations
- Readable typography and clear headings
- Large, clearly labeled buttons
- Consistent navigation
- High-contrast interface elements
- Simple instructions and step-by-step learning

## Functional Requirements
The prototype represents the main learner-facing functional requirements defined in DSOA-7 SRS. It is an interactive UX demonstration, not a fully implemented application.
